# AI Negotiation Arena

Веб-приложение для тренировки переговоров с виртуальным собеседником на базе искусственного интеллекта.

Пользователь проходит интерактивный диалог с AI-персонажем, который следует заданной роли, защищает собственные интересы и меняет поведение в зависимости от аргументов собеседника. После завершения переговоров система должна оценивать результат, отмечать сильные стороны и формировать рекомендации для дальнейшего развития навыков.

> Проект находится на стадии раннего MVP. Сейчас реализован базовый чат с YandexGPT, сохранение контекста диалога в рамках открытой страницы и голосовой ввод через браузер.

## Возможности текущей версии

- обмен сообщениями с YandexGPT через серверный API;
- хранение последних сообщений в контексте диалога;
- ввод текста с клавиатуры;
- голосовой ввод на русском языке через Web Speech API;
- адаптивный интерфейс для настольных и мобильных экранов;
- хранение ключа API только на серверной стороне.

## Планируемые возможности

- каталог учебных сценариев переговоров;
- роли, цели, скрытые интересы и ограничения AI-собеседника;
- настройка сложности, характера и тона диалога;
- изменение поведения AI в зависимости от действий пользователя;
- ограничение количества ходов и времени сессии;
- отдельный AI-модуль оценки завершённых переговоров;
- рейтинг по аргументации, выявлению интересов, работе с возражениями и достижению цели;
- разбор ошибок, улучшенные варианты формулировок и персональный план развития;

## Технологии

- Node.js;
- Express 5;
- JavaScript и браузерный DOM API;
- YandexGPT через OpenAI-совместимый API;
- OpenAI JavaScript SDK;

## Как это работает

Браузер отправляет историю диалога на маршрут `POST /api/chat`. Сервер проверяет сообщения, добавляет системную инструкцию и обращается к YandexGPT. Полученный ответ возвращается в интерфейс. Ключ API не передаётся в браузер и не хранится в клиентском коде.

```text
Браузер -> Express API -> YandexGPT
   ^                         |
   +--------- ответ ---------+
```

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/<username>/ai-negotiation-arena.git
cd ai-negotiation-arena
```

2. Установите зависимости:

```bash
npm install
```

3. Создайте в корне проекта файл `.env`:

```env
YANDEX_API_KEY=your_api_key
YANDEX_FOLDER_ID=your_folder_id
PORT=3000
```

4. Запустите сервер:

```bash
node server.mjs
```

5. Откройте в браузере:

```text
http://localhost:3000
```

## API

### `POST /api/chat`

Принимает историю сообщений:

```json
{
  "messages": [
    {
      "role": "user",
      "content": "Предлагаю обсудить условия поставки"
    }
  ]
}
```

Возвращает ответ модели:

```json
{
  "reply": "Готов обсудить условия. Какой объём поставки вас интересует?"
}
```

## Голосовой ввод

Распознавание речи выполняется средствами браузера. Поддержка зависит от браузера и его настроек доступа к микрофону. Если Web Speech API недоступен, кнопка голосового ввода автоматически отключается, а текстовый чат продолжает работать.

## Безопасность

- файл `.env` исключён из Git;
- API-ключ используется только на сервере;
- сервер принимает только сообщения с ролями `user` и `assistant`;
- в запрос к модели передаются только последние 20 сообщений.

Перед публикацией убедитесь, что `.env` не попал в историю Git. Если ключ когда-либо был опубликован, отзовите его и создайте новый.
